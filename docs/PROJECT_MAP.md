# DeskPilot project map

Read after `AGENTS.md`. Updated November 25, 2026 (semester Week 13).

- **Objective:** CSS 4007 Level A. DeskPilot is a voice- and text-controlled autonomous Windows desktop agent. It plans multi-step goals, uses adapter tools, replans on observations, verifies outcomes and reports. Each action passes a Python policy gate.
- **Architecture:** Python 3.12, uv, Pydantic, LangGraph, OpenAI GPT via `langchain-openai` (configurable, default `gpt-5.6-luna`). It has two policy layers. The request pre-filter (lexicon, fuzzy matching, TF-IDF + logistic regression) can refuse or flag a request but never grants permission. The action gate covers zones, risk classes, approvals and budgets. Adapters are built on an internal SDK, one at a time: files/apps, restricted PowerShell (AST), Playwright browser, search, then the user's browser and UI Automation. The UI is a PySide6 tray app with an island window. Details are in `docs/ARCHITECTURE.md`.
- **Safety invariants:** The hard-deny system zones, forbidden command classes and mandatory approval for dangerous actions are code constants, not settings. Paths are checked after real-path resolution. Approvals are action-bound, single-use and expiring. Voice approval uses a challenge code. All tool output is untrusted.
- **Workflow:** The orchestrator splits roadmap tasks into micro-tasks. These go to Sonnet subagents (`implementer` → `reviewer`, `researcher`), in parallel worktrees when files are disjoint. Briefs and reports are in English, with JSON reports per `docs/agent-report.schema.json`. Each run is logged in `docs/orchestration-log.md`. Tell the user if the review loop burns usage too fast.
