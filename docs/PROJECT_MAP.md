# AgentShield Lab project map

Read after `AGENTS.md`. Updated November 16, 2026.

- **Objective:** CSS4007 Level A. An autonomous Auditor evaluates security, reliability and task correctness of tool-using LLM agents. It chooses tests, uses actual observations to adapt and reports reproducible evidence.
- **MVP:** A synthetic Helpdesk Target with local mock search, status and ticket tools. Start with an S1 legitimate-task vertical slice. Add adversarial and failure scenarios from the proposal. Compare baseline and protected using matched inputs and fresh state. Both retain normal task behavior and share outer containment.
- **Architecture:** Python 3.12+, Pydantic and a CLI. LangGraph owns typed control state, conditional routing, checkpoints and approval interrupts. Configurable OpenAI GPT via `langchain-openai` selects Auditor tools and proposes follow-ups. OpenAI Agents SDK is excluded. SQLite stores checkpoints separately from operation, approval and evidence records. pytest and GitHub Actions verify the application.
- **Evidence rules:** Python checks tool calls, policy decisions, outputs and mock state. Preserve attempted, blocked, executed and inconclusive outcomes. Require a measurable effect for attack success. Record model interpretations separately. Demonstrate at least three model-selected Auditor tools with call IDs and use the registered oracle for final assertions.
- **Safety:** Synthetic data and registered mock operations only. No real accounts, arbitrary shell, filesystem or external API tools. Treat retrieved content and model output as untrusted. Enforce scoped IDs, argument validation, action-bound approvals and independent execution budgets. Reconcile operation IDs on resume to prevent duplicate writes. The mock MVP requires no Docker.
- **State:** Planning only. The instructor Node utilities and stub are present. No Python Auditor, mock Target, live GPT integration or application test results. Week 11 implementation carries into Week 12. Exact GPT model, API access and Python dependency compatibility are unverified.
- **Next:** W11-01 establish and verify a locked Python environment. W11-02 prove one real schema-valid OpenAI tool call. W11-03 adds the CLI before the S1 vertical slice. W14-03 paper selection by December 6. Final deadline December 22 at 23:59 UTC+05.
