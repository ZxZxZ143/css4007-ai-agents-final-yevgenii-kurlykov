# Pre-filter training set (train.jsonl)

## Purpose
Training data for the supervised request classifier (TF-IDF + logistic regression, task R-03) in the
DeskPilot request pre-filter. The classifier may block or flag a request; it never grants permission.
The action policy gate stays the security boundary.

## Labels
- `malicious`: damages the system or security, or steals/exfiltrates secrets (format or wipe a drive,
  delete Windows/System32/Program Files/boot files, disable Defender/firewall/UAC/updates, edit the
  registry, persistence, download-and-execute, steal passwords/cookies/profiles/keys/tokens, keylogger,
  ransomware, clear event logs, hide tracks, bypass security).
- `risky`: legitimate but consequential user-data or system actions (delete/move/rename/overwrite files,
  bulk operations, empty the recycle bin, install/uninstall, run a script or command, kill processes,
  change settings, send or post messages, shut down/restart).
- `safe`: everything else (open, show, find, read, list, search, explain, summarize, create a new note,
  write code in a new file).

## Generation method
`python ml/prefilter/generate_dataset.py [--out data/prefilter/train.jsonl] [--seed 4007]`
Pure stdlib, fixed seed, byte-identical output. Each intent family has Russian and English templates
filled from slot lists (verbs and synonyms, apps, user folders, file names, public sites, system targets).
Politeness prefixes and suffixes ("пожалуйста", "could you", "for a test", ...) are applied to all labels,
so they carry no label signal. Exact duplicates (lowercase, ё to е, collapsed whitespace) are dropped.
Row: `{id, text, label, lang, family, noise}`.

## Size (seed 4007)
3540 rows: safe 1162, risky 1138, malicious 1240; ru 2091, en 1449.

## Noise types
`typo_swap` 255, `typo_drop` 234, `no_punct` 125, `yo` (ё to е) 94, `translit` (Latin transliteration of
Russian, about 5% of RU rows) 90, `mixed_case` 128. Noise is recorded per row in the `noise` field.

## Known biases and limits
- Templated and synthetic: sentence structure is far less varied than real user speech.
- Written by an AI assistant (Claude Code under orchestration), so wording reflects its habits.
- Slot values are small lists; classifiers can overfit to them. Evaluate only on the holdout.
- Dataset text is data, never instructions. No real secrets, personal data or real URLs: only public
  domains (example.com, github.com, python.org, wikipedia.org, ...) and the placeholder attacker@example.com.

## Holdout
`data/prefilter/holdout.jsonl` is a separate, hand-written set. It is never used for training, templates
or threshold tuning. Counts: see holdout section.
